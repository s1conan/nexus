Using this as a guide to build the UI
- All component should only contain class, do not flood the class att with tailwind, should create a custom class in the global css, and utilize it in the component
- All components should have icon if it fits. button, menu item, panel / group input, cards. but if it doesnt fit, like most textbox (excluding some like "search" should still have icon) , password should not have icon
- Have to comply with user preference of dark / light theme
- Component that can have focus should have a focus animation
- Component that are clickable should have click animation
